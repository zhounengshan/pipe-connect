# 接水管 · 水流工坊

手机上点击管道旋转，将左上水源接到右下出口，然后打开水阀。

功能：无限闯关、渐进难度、水流动画、提示、星级评分、音效、浏览器进度保存。通过 HTTPS 成功缓存后可离线重开。

## 开启手机游戏链接

打开仓库 Settings → Pages，选择 Deploy from a branch，Branch 选 main，目录选 / (root)，点击 Save。发布完成后用手机打开 GitHub 显示的游戏地址。

游戏无需安装依赖，无需数据库。index.html 和 sw.js 位于仓库根目录。

已验证 1500 个关卡的预设路线可通关，封闭水源不能误判成功，JavaScript 语法检查通过。尚未执行真实手机浏览器验收。
